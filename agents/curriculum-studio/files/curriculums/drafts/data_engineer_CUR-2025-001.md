## MOD-001: The Life Sciences Data Landscape
**Pillar:** Domain Literacy
**Duration:** 1.5 hours
**Learning Objectives:**
- Identify the key data domains, sources, and data types encountered across pharmaceutical, biotech, and clinical research environments
- Describe the regulatory and governance requirements that shape how data is collected, stored, and used in life sciences organisations

### UNT-001-01: Data Domains and Sources in Life Sciences (0.75 hrs)
**Learning Objectives:**
- Identify the primary data domains in life sciences — clinical trials, pharmacovigilance, lab systems, and commercial data — and explain the role each plays in the data engineering pipeline
- Classify common data sources (EDC systems, LIMS, CTMS, EHR, claims data) by their domain and typical data characteristics

## MOD-003: Diagnosing and Solving Data Pipeline Challenges in Life Sciences
**Pillar:** Problem Solving
**Duration:** 2.0 hours
**Learning Objectives:**
- Analyse data pipeline failures in life sciences contexts — identifying root causes across ingestion, transformation, and delivery stages using structured diagnostic approaches
- Apply AI-assisted techniques to accelerate root-cause analysis and propose remediation strategies for data quality and pipeline issues in clinical and regulatory workflows
- Construct a structured problem-resolution approach that connects pipeline failures to downstream business and compliance impact

### UNT-003-01: Root-Cause Analysis for Data Pipeline Failures (1.0 hr)
**Learning Objectives:**
- Apply a structured root-cause analysis framework to diagnose common data pipeline failures — including schema drift, ingestion errors, and transformation anomalies — using life sciences data scenarios (e.g. clinical trial data delays, missing safety signals)
- Distinguish between upstream data source issues, pipeline logic failures, and downstream delivery problems in a regulated data environment
